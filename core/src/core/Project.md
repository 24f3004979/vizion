# Project documentation

First foundational release for the exploratory analysis tool, 
with cli interface, Loading numerical dataset analysis with simple
topics and automated plot generation.


## Features lock
1. simple cli interface
2. Foundational data type segrigation
3. Encoding interactive walkthrough
    - Applying user asked encoding to dataset
    - Options for applying user asked encoders
    - Null handler options
    
4. Foundational Analysis components
    + Single feature centric dashboard
        - Distribution
        - Value analysis
        - trend
        - basic statistics

    + Single data type features dashboard
        - User interactive feature choice
        - combinations and aggregations based distribution
        - dimentionality reduction view point
        - automated interactive dashboard build

    + Holistic analysis exploration
        - feature interaction score ranking
        - Extensive agregation and pivot plots
        - holistic cross feature trend analysis
        - broad heat map exploitation
        - targeted dashboards
